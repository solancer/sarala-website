# Showcase workspace

The folder the website's screenshots were taken in. Open it in Sarala with
**File › Open Folder…** to retake them with the same content.

- `Welcome to Sarala.md`: a tour of the editor (callouts, tables, tasks, math, Mermaid, code)
- `Kafka/`: a long field guide (outline, Java/Python/YAML code, diagrams)
- `Kubernetes/`: a runbook with a sequence diagram, and an architecture note with Mermaid and D2
- `Notes/Queueing Math.md`: KaTeX equations

Screenshots are the app window at 1400×880 points, captured with its native shadow
and set on a soft gradient, exported as 1680-px-wide WebP into
`public/screenshots/shots/`.
